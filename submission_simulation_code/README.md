# Reproducibility materials for "Rerandomization Under Interference"

This directory contains the code that produces every simulation result and figure in the
manuscript and its online supplementary material. The paper analyzes no external data; all
data are generated by the simulation code, with fixed random seeds.

## Requirements

- Python 3.9 or later
- Python packages: `numpy`, `scipy`, `joblib`, `matplotlib`, `pandas`, `jupyter`
  (the figures were last redrawn with NumPy 2.0.2, SciPy 1.13.1, joblib 1.5.3, Matplotlib 3.9.4)
- A LaTeX installation (Matplotlib's `text.usetex` is used so that figure labels match the paper)

## Files

| File | Purpose |
|---|---|
| `core.py` | Simulation engine: network generation, outcome models, treatment-dependent covariates, rerandomization, shared configuration (`Config`, default seed 2026) |
| `run_variance_reduction.ipynb` | Variance-ratio experiments (Section 5, online Appendix F.5); writes JSON files to `results_vr_data/` |
| `run_conservative_var.ipynb` | Conservative variance estimator, confidence-interval length, coverage, and comparison with alternative constructions (online Appendix F.6); writes JSON files to `results_cv_data/` |
| `run_alternative_inference.py` | Comparison of alternative inference procedures (online Appendix F.7); writes `results_altinf/altinf_results.json` |
| `rerand_quantiles.ipynb` | Critical values $q_{1-\alpha/2}(R^2;p,a)$ and their worst case (online Appendix E.5) |
| `make_figures.py` | Redraws all simulation figures of the paper from the saved JSON output, at print size |

## Workflow

Run everything from this directory.

1. **Simulations.** Execute the batch cells of `run_variance_reduction.ipynb` and
   `run_conservative_var.ipynb` (they loop over all outcome models and balancing sets), and run
   `python run_alternative_inference.py`. Each run saves its results as time-stamped JSON files.
2. **Figures.** Run `python make_figures.py`. It reads the most recent JSON file for every
   (balancing set, outcome model) combination and writes the PDF figures to `figures/`, using the
   file names referenced in the LaTeX source.

Figure 1 of the main text and Figures A.1 and C.1 of the supplement are diagrams drawn in the
LaTeX source; they involve no computation.

Outcome models are indexed by `type`: 1 `lin-prop`, 2 `lin-prop+nwx`, 3 `lin-nwx`, 5 `exp-prop`,
6 `exp-sumexp`, 7 `exp-prop+nwx`, 8 `exp-sumexp-full` (online Appendix F.2). Balancing sets:
`np` = treated-neighbor proportion, `np+nwx` = proportion plus neighborhood averages of
$Z_j \mathbf X_j$.

## Random seeds and parallelization

All random numbers are generated from seeds fixed in the code (`Config.seed = 2026`; sweep point
`i` uses seed `2026 + i`), so results are exactly reproducible. Sweep points can be run in
parallel on one machine with `joblib` (`n_jobs`); the batch cells use `n_jobs=1`.

## Expected run time

On a standard desktop machine, judged from the time stamps of the saved output: about 2.5 hours for
the variance-ratio batch (26 experiments) and about 1–1.5 hours for the conservative-variance batch
(21 experiments); the alternative-inference script and the critical-value notebook take minutes;
`make_figures.py` takes about one minute.
